# CUMCM 2026 LaTeX 模板

本仓库面向中国“全国大学生数学建模竞赛（CUMCM）”。模板按 2026 年全国组委会发布的论文格式规范、参赛规则和 AI 工具使用规定设计。

## 编译

```bash
latexmk -xelatex cumcm.tex
```

主文件是 `cumcm.tex`，公共版式集中在 `cumcm2026.sty`。使用 AI 时，还需填写 `ai-usage-details.tex`，编译后将 PDF 重命名为 `AI工具使用详情.pdf` 并放入支撑材料。

## 交付模式

- 电子版：直接提交 `cumcm.pdf`；第一页必须是摘要页，不得含承诺书或编号专用页。
- 纸质版：使用组委会或赛区当年下发的承诺书作为第一页、编号专用页作为第二页，再装订与电子版内容格式一致的论文。不要自行仿制这两张官方专用页。
- 支撑材料：另行制作 RAR 或 ZIP；论文附录中的文件清单必须与压缩包一致。

## 投稿前检查

1. A4 白纸；四边页边距均不小于 2.5 cm；纸质版左侧装订。
2. 摘要含标题和关键词，原则上不超过一页；摘要页页码为 1，页脚居中。
3. 正文从摘要后的下一页开始；不设置目录；正文不超过 30 页，附录页数不限。
4. 摘要、正文、附录、PDF 元数据、文件名及支撑材料中均不得泄露姓名、学校或赛区。
5. 参考文献在正文引用处标注，并按科技论文规范列出。
6. “AI工具使用声明”位于参考文献之前，且声明与实际使用情况一致。
7. 附录含支撑材料文件列表和全部完整、可运行的源程序；无程序或无支撑材料时使用官方规定的明确表述。
8. 论文电子版为单个 PDF 或 Word 文件，建议 PDF，不压缩且不超过 20 MB；支撑材料压缩包不超过 20 MB。
9. 论文电子版与纸质版的论文内容及格式（含附录）完全一致。
10. 提交前重新编译、运行代码、核对表图，并检查所在赛区是否有额外要求。

## `tabularx` 自定义列

- `Y`：自动换行、水平居中；
- `R`：自动换行、水平右对齐；
- `L`：自动换行、水平左对齐；
- `C{宽度}`：固定宽度、水平居中。

其中 `Y` 和 `R` 均由 `X` 派生，可按剩余宽度自动伸缩。
